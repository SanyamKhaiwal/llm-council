# Security Policy

## Scope

LLM Council is a prompt- and instruction-driven workflow for LLM tools. Security reports may include issues such as unsafe handling of secrets, instructions that expose private information, or documentation that encourages users to disclose credentials.

## Reporting a vulnerability

Please do not publish credentials, private prompts, personal data, or details that could put another user at risk in a public issue.

If GitHub's **Private vulnerability reporting** option is enabled for this repository, use it to report security issues privately. If it is not available, contact the maintainer through the contact options on the [maintainer's GitHub profile](https://github.com/SanyamKhaiwal).

Include a concise description, steps to reproduce, the affected file or workflow, and the potential impact. Redact secrets and private information from logs and examples.

## Supported versions

Security fixes, if any, are expected to target the latest version on the default branch. No separate release or long-term-support policy is currently defined.

## Response expectations

This is a small, independently maintained project, so response time is not guaranteed. Reports will be assessed on a best-effort basis. Please allow time for a response before sharing details publicly.
